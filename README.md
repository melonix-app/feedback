# Melonix Feedback

Bug reports and feature requests for [Melonix](https://melonix.app/) – boards, notes, code snippets, work & pomodoro timers in one calm place.

## How to help
- 🐞 **Found a bug?** [Report it](../../issues/new?template=bug_report.yml)
- 💡 **Have an idea?** [Suggest a feature](../../issues/new?template=feature_request.yml)

Before opening an issue, please check whether someone already reported it.

The Melonix source code is private. This repository is only for feedback.
